# Ответы на контрольные вопросы

### Какой момент времени выбирает PHP для вызова автозагрузчика и что произойдёт, если файл класса так и не найден?
В момент первого обращения к неизвестному классу (new, instanceof, статический вызов). PHP по очереди вызывает все зарегистрированные через spl_autoload_register() функции; если ни одна не подключила файл — фатальная ошибка «Class not found».

### В чём преимущество spl_autoload_register() перед удалённой функцией __autoload()?
Можно зарегистрировать сколько угодно автозагрузчиков (например, свой + Composer), они образуют очередь; __autoload() была одна, её нельзя было дополнить, и в PHP 8.0 её удалили.

### Чем абстрактный класс отличается от интерфейса? Когда что выбрать?
Абстрактный класс хранит и реализацию, и состояние (свойства), наследоваться можно только от одного. Интерфейс — только сигнатуры и константы, реализовать можно много. Абстрактный класс — когда есть общая реализация для семейства («фигура», «сотрудник»); интерфейс — когда нужен контракт «умеет» для несвязанных классов.

### Можно ли создать объект абстрактного класса? Можно ли объявить абстрактное свойство?
Объект создать нельзя — new даст фатальную ошибку. Абстрактных свойств в PHP не существует — абстрактными могут быть только методы; обязательное свойство у наследников обеспечивают конструктором абстрактного класса или абстрактным геттером.

### Чем static-свойство отличается от обычного? Как обратиться к нему внутри и вне класса?
Принадлежит классу, а не объекту: одно значение на все экземпляры. Внутри класса — self::$count / static::$count, снаружи — ИмяКласса::$count. Обычное свойство у каждого объекта своё.

### Что делает модификатор readonly и какие ограничения он накладывает?
Свойство можно записать только один раз (обычно в конструкторе), дальше — только чтение; повторное присваивание и изменение извне дают ошибку. Объявляется только для типизированного свойства (PHP 8.1+).
